이 시안에 쓴 것

  • 방: 받은 크림 방 그림 원본 그대로(방 한 점에 원본 4.5픽셀 — 지금 앱은 1픽셀)
  • 소품 18개: 받은 시트·조명·엽서 원본에서 오림. 놓인 자리·크기는 앱과 같아요
  • 강아지: 지금 그림 그대로(앱도 강아지는 이미 화면 픽셀에 맞춰 그려요)
  • 섞어 보기: 원본이 없는 소품(화분·밥그릇·공·뼈다귀·분재)을 지금 그림으로 키워 넣은 것 — 원본 없이 키우면 이렇게 거칠어요

앱에 넣으려면

  1. 소품 원본: 18개는 있어요. 나머지 48개는 다시 만들 목록대로 받으면 같은 방법으로 오려 바로 넣어요.
  2. 방 원본: 크림 방 하나만 있어요. 분홍·라일락·밤 벽지와 밤 창밖도 같은 크기 원본이 필요해요.
  3. 방 그리기: 방 한 점 단위로 그리던 것을 원본 크기로 — 바닥 칸은 그대로라 소품 자리는 그대로 옮겨져요. 선반·창 자리와 걷기·던지기·개모차 타기는 새 방에 맞춰 다시 잡아요.
  4. 무게: 아지트 그림이 지금 0.8MB → 원본으로 2MB 남짓(처음 한 번만 받아요).
