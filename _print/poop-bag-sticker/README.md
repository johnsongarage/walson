## 보관 시안(안 고른 것 — 지우지 않음, 그림: `drafts/sticker-board-2026-11-17.png`)
- **A 도장형 원형 지름 25mm**(노랑·크림): 응가 그림 + "오늘도 / 해냈다", 둘레 위 "APP WALSON", 둘레 아래 "당신과 강아지의 유의미한 산책".
  영수증 응가 도장과 같은 말·그림이라 앱과 이어진다는 장점, 글씨가 작아 1m에서 덜 읽힘.
- **B 알약형 · 크림**: 고른 것과 같은 그림, 바탕만 크림 — 회색 케이스 위에서 노랑보다 덜 튐.
- **C 뼈다귀형 62×34mm**(노랑·크림): 응가 그림 + "배변봉투 / 장전 완료" + 브랜드 한 줄. 케이스 앞면을 거의 덮어 가장 눈에 띄지만
  케이스 모양에 맞춰야 해서 실측이 꼭 필요, 칼선이 복잡해 인쇄비가 오를 수 있음.
- 다시 뽑으려면 `node render.js` — 모든 시안이 그대로 나온다.

## 시안 세 가지 (색은 노랑 #f2b52f · 크림 #fffaf3, 글씨·그림 갈색)
- **A 도장형 원형 지름 25mm** — 눈알 달린 응가 + "오늘도 / 해냈다"(영수증 응가 도장과 같은 말·그림), 둘레 위 "APP WALSON", 둘레 아래 "당신과 강아지의 유의미한 산책"
- **B 알약형 44×20mm** — 응가 그림 + "똥은 제가 / 치워요", 아래 브랜드 두 줄
- **C 뼈다귀형 62×34mm** — 응가 그림 + "배변봉투 / 장전 완료", 아래 브랜드 두 줄(케이스 모양을 따라감 — 실측 뒤 맞춤)
- 브랜드 두 줄은 홍보물 필수 문구(CLAUDE.md) — `site-config.js`의 `brand`에서 읽는다(문구를 여기 따로 적지 않음).
- 크기는 케이스 실측 전 대략. 케이스를 사서 스티커가 붙을 평평한 면의 가로·세로를 재면 `sticker.html`의 SHAPES 숫자를 고친다.

## 뽑기
`node render.js` (Playwright, 글꼴은 Google Fonts: Black Han Sans · Noto Sans KR) → `out/`
- `sticker-board.png` 시안 비교(실제 크기 3배 + 케이스에 붙인 모습, 케이스 모양은 대략)
- `sticker-test-sheet-A4.pdf` 집에서 A4 라벨지에 뽑아 오려 붙여 보는 시험지(세 시안 모두, 실제 크기, 점선 = 오리는 선, 인쇄 배율 100%)
- `sticker-B-yellow-sheet-A4.pdf` 고른 B 노랑만 A4 한 장에 44장
- 인쇄소용: `sticker-{A,B,C}-{yellow,cream}-print.pdf`(벡터, 글꼴 포함, 사방 재단 여유 1.5mm) ·
  `-600dpi.png`(같은 판, 투명 배경) · `sticker-{A,B,C}-cutline.svg`(같은 판 크기의 자르는 선, 분홍 0.1mm)
- `out/`은 커밋하지 않는다(다시 뽑으면 됨). 시안 비교 그림만 `drafts/`에 남겨 둔다.
