# 치와와 무늬 (바탕 무늬 원본)

앱 바탕에 까는 치와와 무늬(`icons/dog-pattern-{jelly,black,yellow,sea,pink}.svg`)를 만든 재료와 스크립트.
2026-11-17 가르시아가 준 강아지 아이콘 그림(세로 5개씩 5벌)을 선화로 따서 만들었다.

- `icons/set{벌}-{번호}.svg` — 아이콘 25개를 하나씩 벡터로 딴 것. 어떤 그림인지는 `icons-sheet.png`.
- `icons/meta.json` — 아이콘마다 가로·세로 크기(무늬 배치에 씀).
- `extract.py` — 원본 그림 → 아이콘 SVG. `python3 extract.py <원본.png> <내보낼 폴더>` (pip `potracer`, `numpy`, `Pillow`).
  원본 그림은 채팅으로 받은 것이라 여기 넣지 않았다. 아이콘을 다시 딸 일이 없으면 필요 없다.
- `tile.py` — 아이콘 → 무늬 타일(320×320). `python3 tile.py` 하면 `out/`에 세 색이 생긴다(`out/`은 커밋 안 함).
  결과를 `icons/`(저장소 맨 위)에 덮어쓰고 `theme.js`의 무늬 주소 `?v=`를 올린다.

## 무늬에서 뺀 것 (따로 쓸 데가 있다)

금지 표지, 10kg 표지, 응가 자세 — 바탕에 깔면 "하지 마세요"처럼 읽힌다. 나중에 [동네] 시설 안내 아이콘으로 쓸 수 있다:
10kg↓ = 소형견만, 목줄 = 목줄 필수, 금지 = 동반 불가, 킁킁 = 냄새 맡기, 응가 = 응가.

## 확인할 것

원본 그림 한쪽에 생성 도구 표시(✦)가 있었다 — 홍보물·굿즈에 크게 쓰기 전에 그 도구의 상업적 이용 조건을 확인한다.
