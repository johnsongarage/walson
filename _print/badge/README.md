# 왈슨 뱃지 (58mm 핀버튼)

11/16 인터뷰용 뱃지(가르시아가 고른 방식: 바탕 + 그림·글자 한 색, 테두리 원 선 없음, 글자 있음·없음)를 11/18 새 로고(짖는 얼굴)로 다시 그림.
예전 로고로 만든 뱃지가 "멀리서 보면 알아보기 힘들다"(눈)는 후기 때문(DECISIONS 11/18).

- 크기: 재단 지름 70mm(감싸는 부분 포함) = 1654px(600dpi), 보이는 면 58mm, 글자는 지름 52mm 안.
- 글자: 위 WALSON(Archivo Black) · 아래 왈슨(Black Han Sans).
- `make-masks.py` — 새 로고를 판 두 장으로: `face-ink.png`(진한 부분 — 그림 색으로 칠함), `face-cream.png`(눈 흰자·이빨 — 세 색 판만).
  얼굴 노랑·혀는 비워서 바탕색이 비친다(두 가지 색 뱃지).
- `badge.html` — 뱃지 한 개 판. 주소 뒤에 `bg`·`ink`·`text=1`·`cream=1`·`guides=1`.
- `render.js` — 정적 서버(저장소 맨 위, 포트 5181)를 띄우고 `node _print/badge/render.js` → `out/`(커밋 안 함)에
  `badge-<이름>.png`(600dpi), `badge-<이름>-guides.png`(확인용 선), `badges-A4.pdf`(실제 크기 70mm).

## 시안 (2026-11-18)

1 노랑·글자 / 2 노랑 / 3 핑크·글자 / 4 핑크 — 두 가지 색(노랑 #f2b733 + 갈색 #361e12, 핑크 #ff9ab8 + 검정 #161616).
같은 날 가르시아 "뱃지 안에 이미지가 가득 차도록, 글씨 들어간 버전은 그대로" → 그림만 있는 2·4·6은 그림 가로 67.7mm(1600px)로 키워
보이는 면을 꽉 채움(머리 윗선은 보이고 귀 끝은 가장자리에서 잘림). 글자 있는 1·3·5는 그대로.
→ 이어서 "전부 과해, 예전 버전에서 조금만 키워봐" → 2·4·6을 처음(48.7mm)보다 조금 큰 54.6mm(1290px)로 — 귀까지 보이는 면 58mm 안에 다 들어옴.
5 노랑·글자·눈 크림 / 6 노랑·눈 크림 — 눈 흰자·이빨만 크림(#feeab6)을 더한 세 색. 멀리서 보기 비교에서 눈이 가장 잘 보임.
핑크 색은 예전 뱃지 실물 색을 몰라 앱의 딸기우유 분홍으로 넣었다 — 실물과 맞추려면 `render.js`의 값만 바꾼다.
