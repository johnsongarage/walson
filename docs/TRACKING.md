# 사용 통계 설치·보는 법 (2026-11-15)

방문 → 주민증(등록) → 산책(활동) → 다시 옴(재사용)을 운영자 구글 시트에서 보는 방법.
서버·로그인 없이, udigo의 "기기 번호 + Apps Script" 방식과 같다.

## 무엇이 오나
- 앱(`track.js`)이 익명 이벤트를 **자동으로** 보낸다(고지·거부 방식, 11/15). 개인정보 안내에서 "보내지 않기"를 고른 사람과 브라우저 "추적하지 마세요(GPC)"를 켠 사람은 빠진다. 동의는 나중에 가입 단계에서 한꺼번에.
- 오는 것: 무작위 기기 번호, 시각, 화면, 이벤트, 유입 코드(`?from=`), 홈 화면 앱인지, 샘플 모드·운영자 기기 표시, 걸은 시간 구간, 새 발도장 개수 등.
- 오지 않는 것: 위치·경로·발도장 장소, 강아지 이름·사진, 메모, 견주 정보. (`track.js`의 `ALLOWED` 목록에 없는 값은 앱이 버리고, Apps Script도 한 번 더 거른다.)

| 이벤트 | 뜻 | 값 |
|---|---|---|
| `page_view` | 화면을 열었음 | — |
| `card_made` | 주민증을 처음 만듦(= 가입) | 신호등 색, 크기(소·중·대, 고른 경우만 — 아니면 unknown) |
| `card_saved` | 카드 이미지 저장 | 무슨 카드, 저장 모양 |
| `walk_start` | 산책 시작 | 시간만 재기(time) / 길 기록(gps) |
| `walk_complete` | 산책 저장 | 위와 같음, 걸은 시간 구간, 보상 인정 여부 |
| `stamp_new` | 새 발도장 | 개수만 |
| `keyring_given` | 키링 지급(직원 버튼) | — |
| `walk_type_done` / `share_click` | 산책 유형 테스트 결과 / 공유 버튼 | 유형 / 무엇 |
| `store_visit` | 가게 카운터 체크인 QR로 방문 도장(하루 한 번) | 스팟 번호 |

## 설치 (가르시아, 10분)
1. 구글 시트를 새로 만든다(이름 예: `왈슨 통계`).
2. 시트 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 저장소의 `server/track.gs`를 통째로 붙여 넣고 저장.
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱** → 실행: **나**, 액세스 권한: **모든 사용자** → 배포 → 권한 허용.
4. 나오는 **웹 앱 주소**(`https://script.google.com/macros/s/…/exec`)를 Claude에게 주거나, `site-config.js`의 `trackUrl`에 넣는다. 넣고 배포하면 기록이 들어오기 시작한다(11/15 연결 완료).
5. Apps Script 위쪽 함수 목록에서 **`installHourlyTrigger`** 를 골라 한 번 실행(권한 허용). 이후 1시간마다 `요약` 시트가 새로 계산된다.
6. (선택) 보관 기간 지키기: 트리거 추가 → `deleteOldRows`, 시간 기반, 매월. 400일 지난 줄을 지운다(개인정보 안내와 같은 기간).

`track.gs`를 고치면: 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포(주소는 그대로).

## 요약 시트 읽는 법
- **일별**: 방문 기기 / 새 기기 / 다시 온 기기 / 주민증 만듦 / 산책 시작·완료 기기 / 길 기록 산책 / 새 발도장 / 키링
- **유입별**(처음 들어온 경로 기준): 기기 → 주민증 → 산책 완료 → 7일 재방문율. 어떤 홍보가 "써 보는 사람"을 데려왔는지 본다.
- **재방문율**: 첫 방문 뒤 1·7·14·30일 안에 다른 날 다시 온 기기 비율(그 기간이 지난 기기만). 주민증 만든 기기만 따로도 본다.
- 샘플 모드 줄과 운영자 기기(스팟 편집 토큰이 있는 브라우저) 줄은 요약에서 뺀다. 원본은 `log` 시트.

## 월간 리포트 시트(제휴 가게용)
- `월간 리포트` 시트: 달마다 방문 기기 / 새로 온 기기 / 새 주민증 / 산책한 기기 / 산책 수 / 가게 방문(기기·가게) / 새 기기의 다음 달 재방문율 / 크기 소·중·대.
- `요약` 시트 아래 **강아지 크기**: 주민증 기준 소·중·대 비율(고른 것 중).
- 가게에 보여 줄 때는 이 합계만. "기기 기준 추정"이라고 밝히고, 카톡 채널 친구 수·키링 현장 명단처럼 제3자가 보증하는 숫자를 같이.

## 가게 체크인 QR(② 방문 연결)
- 스팟 편집 목록에서 동반 스팟의 **체크인 QR** 버튼 → A4에 카운터 카드 2장 인쇄(`checkin-qr.html`). 모두에게 반영된 스팟만 된다.
- 손님이 찍으면 `visit.html`에서 방문 도장 + `store_visit`. 같은 기기는 가게마다 하루 한 번. 주민증이 없으면 "주민증 만들기"로 안내.
- 요약 시트 **가게 방문**: 방문한 기기 / 방문 횟수 / 두 번 이상 온 기기 / 이번 달 / 이 QR로 왈슨을 처음 안 기기. 제휴 가게에는 이 합계만 보여 준다(기기별 기록은 넘기지 않음).
- 가게 직원이 시험 삼아 찍으면 숫자에 들어간다 — 시험은 운영자 기기(스팟 편집 토큰 있는 브라우저)로.
- 가게 동의 없이 그 가게 이름으로 QR을 만들어 붙이지 않는다(브랜드·제휴 오해).

## 운영 팁(11/15 검토)
- **잠금(LockService)**: 기록(`doPost`)은 `appendRow`가 원자적이라 동시에 와도 줄이 겹치지 않아 잠그지 않는다(잠그면 몰릴 때 오히려 기다리다 버려짐). 요약 계산·오래된 줄 지우기만 한 번에 하나 돌게 잠근다.
- **한도**: GPS 점마다 보내지 않는다 — 화면 열기와 핵심 행동(주민증·산책 시작/끝·도장·키링)만. 하루 100명이 써도 수천 줄 수준. 무료 계정 한도에서 걸리는 쪽은 동시 실행(약 30개)과 트리거 실행 시간(하루 90분) — 요약 계산은 줄이 수십만 개가 되면 길어지니 `deleteOldRows`(400일)를 켜 두기.
- **track.gs를 고치면** 배포 관리 → 새 버전으로 다시 배포해야 반영된다(주소는 그대로).

## 숫자가 틀어지는 지점
- **한 사람이 여러 기기로 셀 수 있다**: 카톡 안 브라우저 / 사파리·크롬 / 홈 화면 앱은 저장 공간이 따로라 각각 다른 번호. → 실제 사람 수보다 많게 나온다.
- **아이폰 사파리는 7일 넘게 안 열면 저장 내용을 지울 수 있다** → 재방문이 새 기기로 잡혀 재방문율이 낮게 나온다. 홈 화면에 추가한 앱은 예외 → 공원에서 홈 화면 추가를 같이 권하기.
- **끈 사람(보내지 않기·GPC)은 안 셈** → 약간 적게 나올 수 있다.
- 그래서 정확한 머릿수보다 **추세와 통로별 비교**로 본다. 여러 기기를 한 사람으로 묶는 건 로그인(서버 1단계) 뒤에.

## 여러 유저 시뮬레이터 (개발 중 시험, 2026-11-15)

지금 시트를 **시험용**으로 쓰고, 실제 서버를 세팅할 때 새로 만든다는 전제.

- 여는 곳: 스팟 편집 위쪽 **시뮬레이터** (GitHub 토큰을 넣은 브라우저에서만 열림) → `simulate.html`
- 가짜 사용자 N명 × 지난 D일을 만들어, 기기 하나당 한 번(`{tt:1, batch:[…]}`)씩 보낸다. 날짜는 보낸 쪽 날짜를 쓴다(테스트 기록만).
  위치·이름·사진은 만들지 않는다(통계에 원래 없는 것).
- 테스트 기록은 log의 **테스트** 칸이 1 → 운영 `요약`·`월간 리포트`에서 빠지고 `요약(테스트)`·`월간 리포트(테스트)`에만 나온다.
- 실행마다 유입 코드가 `s<실행번호>_poster` 처럼 붙어서, **시트 결과와 비교**는 이번 실행분만 정답과 맞춘다(기기·주민증·산책 완료·7일 재방문).
- **부하 시험(30명 동시)**: 30건을 한꺼번에 보내고 몇 건이 기록됐는지 본다(Apps Script 동시 실행 한도 확인용).
- 지우기: Apps Script 편집기에서 함수 `deleteTestRows` 실행 → 테스트 줄과 테스트 시트만 지움.
- **첫 홍보 전**: log 시트를 통째로 비우고 시작한다(개발 중 내 기기·시험 기록이 실제 숫자에 섞이지 않게).
- track.gs가 바뀌었으니 Apps Script에 새 코드를 붙여 넣고 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 시뮬레이터가 동작한다.
