# 사용 통계 설치·보는 법 (2026-11-15)

방문 → 주민증(등록) → 산책(활동) → 다시 옴(재사용)을 운영자 구글 시트에서 보는 방법.
서버·로그인 없이, udigo의 "기기 번호 + Apps Script" 방식과 같다.

## 무엇이 오나
- 앱(`track.js`)이 **동의한 사람만**(처음 화면 아래 "괜찮아요") 익명 이벤트를 보낸다.
- 오는 것: 무작위 기기 번호, 시각, 화면, 이벤트, 유입 코드(`?from=`), 홈 화면 앱인지, 샘플 모드·운영자 기기 표시, 걸은 시간 구간, 새 발도장 개수 등.
- 오지 않는 것: 위치·경로·발도장 장소, 강아지 이름·사진, 메모, 견주 정보. (`track.js`의 `ALLOWED` 목록에 없는 값은 앱이 버리고, Apps Script도 한 번 더 거른다.)

| 이벤트 | 뜻 | 값 |
|---|---|---|
| `page_view` | 화면을 열었음 | — |
| `card_made` | 주민증을 처음 만듦(= 가입) | 신호등 색 |
| `card_saved` | 카드 이미지 저장 | 무슨 카드, 저장 모양 |
| `walk_start` | 산책 시작 | 시간만 재기(time) / 길 기록(gps) |
| `walk_complete` | 산책 저장 | 위와 같음, 걸은 시간 구간, 보상 인정 여부 |
| `stamp_new` | 새 발도장 | 개수만 |
| `keyring_given` | 키링 지급(직원 버튼) | — |
| `walk_type_done` / `share_click` | 산책 유형 테스트 결과 / 공유 버튼 | 유형 / 무엇 |

## 설치 (가르시아, 10분)
1. 구글 시트를 새로 만든다(이름 예: `왈슨 통계`).
2. 시트 메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 저장소의 `server/track.gs`를 통째로 붙여 넣고 저장.
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱** → 실행: **나**, 액세스 권한: **모든 사용자** → 배포 → 권한 허용.
4. 나오는 **웹 앱 주소**(`https://script.google.com/macros/s/…/exec`)를 Claude에게 주거나, `site-config.js`의 `trackUrl`에 넣는다. 넣고 배포해야 동의 안내가 뜨기 시작한다.
5. Apps Script 위쪽 함수 목록에서 **`installHourlyTrigger`** 를 골라 한 번 실행(권한 허용). 이후 1시간마다 `요약` 시트가 새로 계산된다.
6. (선택) 보관 기간 지키기: 트리거 추가 → `deleteOldRows`, 시간 기반, 매월. 400일 지난 줄을 지운다(개인정보 안내와 같은 기간).

`track.gs`를 고치면: 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포(주소는 그대로).

## 요약 시트 읽는 법
- **일별**: 방문 기기 / 새 기기 / 다시 온 기기 / 주민증 만듦 / 산책 시작·완료 기기 / 길 기록 산책 / 새 발도장 / 키링
- **유입별**(처음 들어온 경로 기준): 기기 → 주민증 → 산책 완료 → 7일 재방문율. 어떤 홍보가 "써 보는 사람"을 데려왔는지 본다.
- **재방문율**: 첫 방문 뒤 1·7·14·30일 안에 다른 날 다시 온 기기 비율(그 기간이 지난 기기만). 주민증 만든 기기만 따로도 본다.
- 샘플 모드 줄과 운영자 기기(스팟 편집 토큰이 있는 브라우저) 줄은 요약에서 뺀다. 원본은 `log` 시트.

## 숫자가 틀어지는 지점
- **한 사람이 여러 기기로 셀 수 있다**: 카톡 안 브라우저 / 사파리·크롬 / 홈 화면 앱은 저장 공간이 따로라 각각 다른 번호. → 실제 사람 수보다 많게 나온다.
- **아이폰 사파리는 7일 넘게 안 열면 저장 내용을 지울 수 있다** → 재방문이 새 기기로 잡혀 재방문율이 낮게 나온다. 홈 화면에 추가한 앱은 예외 → 공원에서 홈 화면 추가를 같이 권하기.
- **동의 안 한 사람은 안 셈** → 전체 사용자보다 적게 나온다. 동의율 자체는 알 수 없다.
- 그래서 정확한 머릿수보다 **추세와 통로별 비교**로 본다. 여러 기기를 한 사람으로 묶는 건 로그인(서버 1단계) 뒤에.
