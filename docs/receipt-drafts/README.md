# 영수증 개편 시안 (2026-11-23)

가르시아: "영수증을 좀 개편할 거야. 너무 글씨가 빽빽해서 안 보여. 새로운 시안 기획으로 3개 줘 봐."

- 지금 영수증은 줄이 20개 안팎이라 종이를 0.85배로 줄여 그린다. [기록] 탭 미리 보기(폭 약 310px)에서 본문이 약 8px, 작은 글씨가 약 6px.
- 시안은 모두 스토리 9:16(1080×1920). 본문 52px(미리 보기에서 약 15px), 큰 숫자 118~128px.
- 세 시안 모두 위치·경로·장소 이름·산책한 시각은 넣지 않는다(지금과 같음). 아래 브랜드 줄은 site-config.js `brand`.

| 시안 | 한 줄 | 남기는 것 | 빼는 것 |
|---|---|---|---|
| 1 정리한 영수증 | 모양은 그대로, 줄은 절반, 글씨는 두 배 | 가게 이름, 대표·번호·날짜 한 줄, 산책 시간·거리(큰 숫자), 응가·킁킁·발도장 칸 셋, 특이 사항, 산책 빚 + 상환 도장 + 응가 도장, 결제 농담 한 줄, 바코드·브랜드 | 품목/수량 머리, 꾸준함 도장 줄, 오늘 목표 줄(→ "오늘 목표 달성" 딱지), 이월·교환 농담 두 줄, 주소 비공개 줄 |
| 2 사진이 주인공 | 사진을 꽉 채우고 아래에 영수증 조각 한 장 | 이름·날짜·번호, 큰 숫자, 알약 셋(응가·킁킁·발도장), 특이 사항, 바코드·브랜드, 도장은 조각 모서리에 스티커처럼 | 산책 빚 줄·농담 줄 전부(도장으로만) |
| 3 젤리 핑크 카드 | 리뉴얼 색(젤리 핑크), 큰 숫자 칸 셋, 영수증은 톱니·도장으로만 | 이름 딱지, 시간·거리·응가 칸, 특이 사항 말풍선, 산책 빚 + 도장 | 킁킁·발도장(칸이 셋이라), 바코드 |

- 피드 4:5(1080×1350)는 고른 시안으로 따로 맞춘다.
- `index.html`: 지금 영수증과 세 시안을 같은 지어낸 산책으로 그려 비교하는 시험 화면(앱에서 연결 안 함). 내 사진·특이 사항을 바꿔 볼 수 있고, 이 휴대폰 안에서만 그린다.
